# Nexus · 3x-ui 线路管理台

Nexus 是面向 3x-ui 3.4.2 的中文网页。Rust 服务部署在服务器上，管理员用浏览器接入各台面板的 API。

首次安装、远程访问、升级和回滚请参阅[服务器部署指南](DEPLOY.md)。

## 在 Linux 服务器上启动

在装有 Docker Engine 和 Compose 的服务器上进入本项目目录。首次部署时创建仅自己可读的 `.env`，填入管理台登录密码。

```sh
umask 077
touch .env
chmod 600 .env
nano .env
```

在文件中设置 `NEXUS_ADMIN_PASSWORD='你的独立长密码'`。可选的 `NEXUS_PANEL_DELETE_PASSWORD` 用于删除面板时确认，留空时使用管理网页登录密码。升级时若要沿用原来的删除密码，在服务器自己的 `.env` 中填入原值。使用预构建的 Linux amd64 镜像时，将 `dist/nexus-web-linux-amd64.tar.gz` 和 `compose.yaml` 上传到服务器，保留下列路径后执行。

```sh
docker load -i dist/nexus-web-linux-amd64.tar.gz
docker compose up -d --no-build
```

也可上传完整项目，在项目目录执行 `docker compose up -d --build` 从源码构建当前服务器架构的镜像。

默认发布到服务器的 `127.0.0.1:8787`。浏览器登录账号为 **admin**，密码来自 `.env`。如果通过域名远程访问，将域名的 DNS 指向服务器，在该服务器的 Caddy 配置中添加以下站点，并重载 Caddy。替换示例域名后，从浏览器打开自己的 HTTPS 地址。

```caddyfile
nexus.example.com {
    reverse_proxy 127.0.0.1:8787
}
```

也可以在自己的电脑上执行 `ssh -L 8787:127.0.0.1:8787 user@server`，保持 SSH 连接，然后打开 [本地网页](http://127.0.0.1:8787)。如果改用其他反向代理，向管理台转发浏览器请求的原始 Host 和 Authorization。

## 接入面板并开通线路

1. 在首页点击 **接入面板**，填写面板名称、含自定义基础路径的地址，以及 3x-ui 的 API 令牌。如果面板地址仅供管理使用，另填客户端可访问的分享域名或 IP。默认勾选接入后同步，已有的 VLESS + TCP + Reality 线路会出现在 **我的线路** 中。
2. 在 **新建线路** 输入名称和 SOCKS5 出口。使用期限默认留空，线路永久有效。也可选择 1、2、3、6 个月或 1 年，再次点击可取消。出口支持 `socks5://用户:密码@主机:端口` 或 `主机:端口:用户:密码`。点击创建后，服务端通过 API 配置 VLESS + TCP + Reality 入站、客户端、SOCKS 出站及路由。客户端标识、入站名称与出站标签使用填写的名称。
3. 创建成功后可复制 VLESS 链接、复制带名称的二维码图片或下载 PNG。分享地址应能通过分配的 TCP 端口访问目标面板主机上的 Xray。自动分配的 TCP 端口默认为 20000–20999，可在管理台的 .env 中用 `NEXUS_LINE_PORT_RANGE=起始端口-结束端口` 指定实际范围，更新后重新运行 `docker compose up -d`。在运行 3x-ui 的服务器上放行这段端口，或仅放行分享链接中的实际端口；管理网页自身使用 8787。
4. **我的线路** 显示上方 **目标面板** 的线路，每页 12 条。切换面板会回到第一页；搜索会检索所选面板的全部线路。页面可见时，每 30 秒从 API 刷新在线状态、上下行流量和客户端到期日。直接在 3x-ui 中新增、修改或删除线路后，在 **面板管理** 找到该面板，点击 **同步** 即可更新登记和分享链接。同步结果会列出新增、更新、移除和跳过的数量。
5. **面板管理** 中点击 **删除** 需要输入统一删除密码。删除会移除当前管理台保存的连接、令牌和关联线路登记。3x-ui 上的入站、客户端和其他配置仍可继续使用。
6. **数据备份** 中单独下载某一面板时，文件名使用面板连接地址里的域名和浏览器当天的日期，例如 `hk.example.com-2026-11-27.db`。PostgreSQL 面板对应 `.dump`。选择多个面板或一键备份全部会下载 ZIP，每台面板的文件也按此命名，同名文件追加序号。ZIP 内的 `manifest.json` 记录面板与文件的对应关系以及失败原因。

Nexus 自身的线路登记、令牌和操作记录保存在 Docker 卷 `nexus-data`。升级时沿用原部署目录、Compose 项目名、`.env` 和数据卷，加载新版镜像后执行 `docker compose up -d --no-build`。

在 **创建线路** 左边点击 **批量创建线路**，选择面板和使用期限。将名称列表粘贴到 **线路名称**，将对应的地址列表粘贴到 **SOCKS5 出口**，每个输入框每行填写一项。页面实时显示两列的数量，数量和行位置对齐后即可创建。部分失败时，两列会留下对应的失败行，修改后可以单独重试。

单条和批量创建均可直接输入到期时间，例如 `2027-04-22 12:36:10` 或 `2026/12/4 18:01:13`。时间按当前浏览器所在时区解释。流量上限可手填 GB 数值，也可点选 **100 GB**、**200 GB** 或 **500 GB**。留空为不限流量。批量创建时，每个客户端分别获得所填额度。

在 **面板管理** 点击名称旁的 **访问面板**，可在新标签页打开对应的 3x-ui 网页，保留接入时所填的管理端口和自定义路径。

面板名称右侧的 **备注** 可添加、修改或清空。备注保存在 Nexus 管理台中，搜索面板时也可以输入备注。

## Reality 目标与线路连通性

自动开通默认使用 `www.amd.com:443`。管理台调用目标面板的 Reality 检测 API，从面板所在网络验证 TLS、HTTP/2 和证书，再把可用的域名写入入站的 SNI 列表。分享链接和二维码使用该列表中的一个域名。要指定其他默认目标，在部署目录的 `.env` 设置 `NEXUS_REALITY_TARGET=域名:端口`，再运行 `docker compose up -d`。

旧线路显示延迟 `-1` 时，在 **线路管理 → 我的线路 → 检测与修复** 打开对应线路。**检测并修复 Reality** 会检测目标，更新该专用入站，并生成新分享链接。请在客户端重新导入链接或二维码。也可以点击 **测试 SOCKS5 出口**，让面板通过同名出口访问面板设置的出站测试网址。该测试只测出口这一段，客户端仍须能连到分享地址及其 TCP 端口。

## 在工作台管理客户端

线路管理的 SOCKS5 出口输入框默认显示输入内容。打开 **工作台 → 客户端管理**，即可从面板当前配置复制 VLESS + TCP + Reality 链接或查看带名称的二维码。一个客户端绑定多个可分享的入站时，可按入站选择链接。

点击客户端所在行的 **状态** 开关即可启用或停用该客户端。管理台会通过 3x-ui API 保存更改，再读取该客户端的实际状态。

勾选一个或多个客户端，点击 **复制选中链接**，即可复制每行当前所选入站的 VLESS 链接，每条链接占一行。点击 **导出 XLSX** 可在下载前确认导出列。默认列依次为节点名称、VLESS 链接、到期时间和二维码。每行二维码都是嵌在工作簿里的图片，可以离线扫码。

勾选一个或多个客户端，点击 **增加时间**，可以追加 1、2、3、6 个月、1 年，或自定义天数。有效期内的客户端从原到期日顺延。已到期或永久有效的客户端从本次操作时起计算新的到期日。按首次使用计时且尚未激活的客户端会延长可用时长。

要指定到期时刻，点击客户端所在行的 **改期**，或在 **批量改期** 中选择多个客户端。可以直接粘贴 `2027-04-22 12:36:10` 或 `2026/12/4 18:01:13`，也可从日历选择。时间按浏览器所在时区计算，留空表示永久有效。

**已用 / 流量上限** 显示客户端本周期上传与下载的合计和当前额度。勾选一个或多个客户端后，点 **修改流量上限** 为每人设置相同额度，点 **不限** 可移除限制。点 **重置已用流量** 并确认，会通过 3x-ui 清零所选客户端所有绑定入站的本周期用量；3x-ui 也会尝试重新启用已停用的客户端。单个客户端可直接使用所在行的 **改上限** 或 **重置流量**。

列表最右侧的 **备注** 可以直接编辑。勾选多个客户端可统一添加、替换或清空备注。备注通过 API 保存到 3x-ui 客户端的备注字段，搜索框可以按备注、客户端名或关联入站名称查找。

可以删除一名客户端，也可以勾选多名客户端后批量删除。确认后，管理台通过 3x-ui API 删除客户端，并清理专用入站、关联路由及没有其他引用的专用出站。仍被其他客户端使用的配置会保留。某台面板在操作中途掉线时，可在客户端管理页重试待清理项目。

## 核对和修正线路路由

在 **高级管理 → 出站管理** 可测试 SOCKS5 出口的延迟。**TCP** 测所属面板连接 SOCKS5 服务器所需的时间，**HTTP** 测该面板通过 SOCKS5 访问其出站测试网址所需的时间。点击行内测试按钮可单测，点击 **全部测试** 会测试当前面板筛选和搜索条件下所有页的 SOCKS5 出站。结果按模式分别显示，单位为毫秒。

开通线路后，在 **出站管理** 可以看到每个 SOCKS5 出站对应的用户。例如线路名为 `墨西哥200.36.3.157` 时，3x-ui 路由规则的「用户」和「出站标签」都填入这个名称，「入站标签」留空。打开 **路由管理** 可按面板查看实际生效顺序。采用 3x-ui 默认配置时，前三条依次处理 API、私有地址和 BitTorrent，第一条线路排在第 4 位，后续线路依次排列。

升级后，要修正某台面板的旧线路，在 **路由管理 → 修正旧版线路路由** 选择面板，点击 **修正规则**。管理台会核对已登记线路的客户端、入站、同名 SOCKS5 出站和旧版规则，转换能确认的旧规则，并显示修正及跳过的数量。如果直接在 3x-ui 改过线路，可先到 **面板管理** 同步一次。

## 本地开发预览

在具备 Rust 和 C 编译工具链的本机运行 `cargo run --locked`，打开 [本地网页](http://127.0.0.1:8787)。源码运行默认监听回环地址。可通过 `NEXUS_BIND` 和 `NEXUS_PORT` 指定监听地址与端口，使用 `NEXUS_DATA_DIR` 指定持久化目录。非回环监听需要设置 `NEXUS_ADMIN_PASSWORD`。
